## Licence: not stated

There is no licence text in the archives, the font files carry none (name ID 0 reads "Generated by Fontographer 3.5" or
"TCVN-5712", no ID 13/14, fsType 0 = installable embedding) and the download page names no terms. They have circulated
freely since the 1990s, but nothing here grants a right to redistribute them. The outlines are probably derived from a
commercial Times design (unverified). Decide before shipping the pack to others.

Owner decision 10/11/2026: government-issued TCVN3 fonts, used as they are. Alternative with a clear licence (worse line metrics): `viewer/fonts/vn/` (same names, same TCVN3 code layout, built from Tinos under OFL 1.1).
`node viewer/tools/font-pack.cjs --vn open` installs that set instead.

## Known gaps of the originals (checked against the TCVN3 table in vn-src/tcvn3.json)

- VHTIME.TTF (.VnTimeH Regular) has no glyph for byte 0xB7.
- VHTIMEBI.TTF (.VnTimeH Bold Italic) has no glyph for bytes 0xA4, 0xA5, 0xA6.
- Byte 0xAD (ư) is U+00AD (soft hyphen) in the document text; the editor treats it as an invisible hyphen (also with these originals).
